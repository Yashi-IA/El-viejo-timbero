# El Viejo Timbero — Versión Plana (Sin Subcarpetas)

Todos los archivos (10 páginas HTML, `styles.css`, módulos `.js`, `resultados.json`, `robots.txt`, `sitemap.xml`, `ads.txt` y `netlify.toml`) están en la misma raíz para que puedas seleccionarlos todos juntos y subirlos directo a GitHub o Netlify sin perder subcarpetas.

## Cómo publicar

1. Descomprimí el ZIP en una carpeta vacía.
2. En **GitHub**: subí los 25 archivos juntos a la raíz del repositorio (y borrá cualquier `_redirects` viejo si existía).
3. En **Netlify**: o bien conectá ese repo de GitHub, o arrastrá la carpeta descomprimida al recuadro de **Deploys**.
4. Reemplazá `pub-0000000000000000` en `ads.txt` por tu ID real de Google AdSense.
